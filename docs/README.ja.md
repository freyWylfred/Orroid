# Orroid 🎮

.NET 10 Android バトルゲームアプリ

🇺🇸 [English README](../README.md)

## スクリーンショット

```
┌─────────────────────────┐
│    ████████████████     │  ← 敵HPゲージ
│         👾              │  ← 敵キャラクター
├─────────────────────────┤
│       HP: 100           │  ← プレイヤーHP
│      ┌───────┐          │
│      │連打切り│          │  ← 円形ゲージ付き
│      └───────┘          │    スキルボタン
│      ┌───────┐          │
│      │速攻切り│          │
│      └───────┘          │

│      └───────┘          │

```

## 機能

### 🎯 スキルシステム
| スキル | 効果 | ダメージ |
|--------|------|----------|
| 連打切り | 高ダメージ攻撃 | 20〜35 |
| 速攻切り | 中ダメージ攻撃 | 15〜25 |
| 防御 | 次の敵攻撃を無効化 | - |

### ⏱️ ゲージシステム
- 各スキルに**円形ゲージ**が付属
- 時間経過で**時計回りにチャージ**（約5秒で満タン）
- ゲージが満タンになるとスキル使用可能
- スキル使用後、**他のゲージが-25%**のペナルティ

### 👾 敵AI
- **2秒ごと**に自動攻撃
- ダメージ: 8〜15

### 🏆 勝敗条件
- **勝利**: 敵のHPを0にする → 敵が消え、獲得経験値とゴールドが表示される
- **敗北**: プレイヤーのHPが0になる

## 技術スタック

- **フレームワーク**: .NET 10 Android
- **言語**: C# 13
- **UI**: Android Native (XML Layout)
- **カスタムビュー**: CircularGaugeView（円形プログレス）

## ビルド方法

### 必要環境
- Visual Studio 2022 (17.12以降)
- .NET 10 SDK
- Android SDK (API 24以上)

### ビルド手順
```bash
# クローン
git clone https://github.com/freyWylfred/Orroid.git
cd Orroid

# ビルド
dotnet build

# または Visual Studio で Orroid.slnx を開いてビルド
```
